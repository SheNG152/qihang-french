# 启航法语设计概览

启航法语是一款中法双语学习应用。用户从词汇、语法或口语进入，按自己的进度学习、练习和复习。界面以苹果备忘录和 Linear 的简洁度为参照，用清晰的布局和操作反馈减少阅读负担。改动应同时让用户更容易使用、维护者更容易修改、AI 更容易核对行为。

## 产品与交互

- **先把主流程做清楚。** 一个页面优先解决一件事。主要操作放在顺手的位置，图标有可访问的名称。说明用于帮助用户完成操作，设置或教程承载较长的解释。
- **界面保持稳定。** 选错、重答、播放和显示反馈时，保持按钮位置与原有节奏。切换主题让文字、图标和状态颜色协调，沿用文字字号和排版。动画服务于切换、按压反馈和完成操作。
- **内容与状态分开。** 相同词条在教材、导入本和复习本中复用学习进度。独立的词性和词义按既有词条关系处理。变位原形与各时态可单独练习并维护状态。
- **从原入口返回。** 按场景保留学习位置。继续练习恢复当前组、题目、选项和位置，调整组量及练习设置按现有生效时机处理。
- **让动作可预期。** 用户能看见正在播放、保存或处理的状态，失败后可以重试。清除记录、替换数据和重置进度前，让用户看到影响范围。

## 改动时守住这些行为

- **学习记录。** 保留词条 ID、词形 ID、学习日期、手选主释义和未完成练习。需要合并或拆分词条时，明确旧记录如何映射，并验证已有数据能继续使用。
- **复习。** 正常到期与额外加练按现有规则计算，延期沿用原学习日期。继续当天未做完的组时，核对组内顺序、题目位置和当日总量。每轮错误统计与同题立即重答分别处理。
- **题目与音频。** 同一次练习中的干扰项内容保持稳定。选择题排除同词的变形、派生形式和几乎同义的释义。更改词形、例句或主释义时，一起核对音标、释义、例句和语音是否对应。导入优先完全匹配，有歧义才交给用户选择。
- **口语。** DELF 使用本机转写和联网考官。桌面朗读、日常练习和口语小镇以当前分支的实际入口及资源要求为准。验证时把页面打开、模型加载、麦克风录制、识别结果、考官回复和保存回听分别核对。
- **隐私与授权。** 分享包、仓库和公开日志仅包含可分发内容。学习历史、原始录音、绑定凭证、签名私钥、私有教材和未获授权的资源留在其授权位置。模型按相应许可和既有独立分发方式处理。

## 用 AI 更新这份项目

1. 让 AI 先读 [AGENTS.md](../AGENTS.md)、本概览和目标模块，再检查当前分支、工作区差异及已有的构建命令。项目交接记录可帮助找入口，实际行为以所检出的代码和相应运行验证为准。 [项目接手记录](AI_PROJECT_CONTEXT.md)
2. 提供平台、复现步骤、期望行为和必须保留的交互或数据。把改动保持在目标模块，优先复用已有逻辑，并保留贡献者工作区里已有的编辑。
3. 按改动选择验证。词汇规则至少核对新练习、续练和旧记录。界面改动检查不同窗口大小、键盘和返回路径。口语改动区分真实模型或服务与测试替身。
4. 在 PR 中写明用户能看到的变化、修改入口、执行过的验证和仍有待验收的设备或依赖。构建、签名、真实设备和实际服务分别报告。 [贡献说明](../CONTRIBUTING.md)
