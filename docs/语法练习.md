# 语法练习（Grammaire）

面向 A1 阶段中文母语学习者的语法专项练习。内容全部来自《Inspire 1 语法整理》文字稿（Leçon 1–14），
不引入教材以外的语法点，也不提前讲后面课的内容。

## 1. 练习内容

| 项目 | 说明 |
| --- | --- |
| 覆盖范围 | Unité 1–4，Leçon 1–14，共 41 个语法点 |
| 素材结构 | 每点含「教材原文 / 规则 / 形式 / 例句 / 中文学习者易错 / 一句话记住」六段 |
| 练习素材 | 180 条例句与 131 条易错例；带教学批注、正误并列或对照写法的条目保留在资料中，不直接作为单选题 |
| 技巧课 | L7、L11 无独立语法点，显示产出检查清单，提示先复习本单元前几课 |
| 单元小结 | 每个单元附 Expressions utiles 原句速览（共 69 条） |

题型两类，均由素材原句派生，不臆造知识点：

1. **中译选句（Trouver la bonne phrase）** — 给中文，从法语选项中选出正确表达。
   干扰项取自该语法点「中文学习者易错」里的 × 错句，正误差异正好落在冠词、变位、语域等考点上。
2. **判断正误（Vrai ou faux）** — 给一句法语，判断是否符合语法规则。错句来自 × 例子，
   正确句来自教材给出的 √ 改写，答后展示「正确说法 + 为什么错」。

## 2. 交互方式

```
左侧模式栏 → 语法练习
   ├─ 首页：进度、继续、教材 / 课时选择（单元目录）、开始学习、综合练习
   ├─ 开始学习：本课概览 → 点击语法点 → 每页一个语法点 → 下一个语法点 → 开始或继续课时练习
   ├─ 默认每轮 10 题：选择 → 确认 → 对/错、正确表达、规则 → 下一题
   └─ 结果页：本轮正确率、错题清单、重练错题 / 返回课次
```

- 选项支持点击，也支持 `A/B/C` 键选择、`Enter` 提交或进入下一题（桌面端）。设置页打开时不接收语法快捷键。
- 每答一题即时写入进度：某语法点累计答对率 ≥ 60% 且作答 ≥ 2 次，记为「已掌握」，课次卡片进度条随之推进。
- 返回键或 Esc 在语法页内逐层返回；范围页再次返回会打开模式栏。离开答题页可从范围页继续上一轮。
- 各单元综合练习与各课时练习分别记忆。未完成的综合练习恢复原题目、选项顺序和答题位置；更换范围、调整设置或学习其他课时均不覆盖它。全部答完后，下一次点击综合练习才会重新组卷。
- 综合练习按所选单元组卷（全部单元时覆盖全书），不区分已学 / 未学；题型、题数及乱序设置只用于新一轮。
- 技巧课检查清单、单元小结实用句型均直接读取分支题库原文，不生成额外教材总结。
- 左侧独立设置页提供通用、词汇、语法和口语设置；语法可设置每轮 5/10/15/20 题、题型与乱序。修改从下一轮生效。

## 4. 数据与维护

- 题库文件：`src/grammar/grammar-data.json`（约 71 KB，构建时随源码打包）。
- 生成脚本：`scripts/build-grammar.py`，需要 Python 3 与 `python-docx`：

```bash
python scripts/build-grammar.py <语法整理docx根目录> src/grammar/grammar-data.json
```

docx 根目录下应是 `Unite1..Unite4`，每个文件命名形如 `U1_L1_Saluer.docx`。
脚本按「语法点 N」与六段标记切分，把 × / √ 易错例拆成 `wrong / right / why` 三列。
新增课次后重新执行即可，前端无需改动。

## 5. 已知限制

- 只做了「选句」和「判断」两类客观题，没有开放式改写题或听力题。
- 技巧课与单元小结不出题，仅作为复习清单与句型速览展示。
- 语法进度只存在本机浏览器存储中，不参与现有备份/导出流程。
